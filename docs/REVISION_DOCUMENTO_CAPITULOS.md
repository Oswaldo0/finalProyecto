# Revision del documento capitulos 1 al 6

Archivo revisado: `capitulos_1_al_6_revision.docx`

Archivo corregido: `capitulos_1_al_6_corregido.docx`

## Comparacion con la aplicacion

La aplicacion implementada corresponde a un sistema web con frontend en React/Vite, backend en Node.js/Express y base de datos MySQL. Sus modulos principales son autenticacion, usuarios, consultas, anotaciones, equivalencias, absorciones, retiro de ciclo, penalidades e informes con dashboard, filtros, graficos, historico e impresion.

## Inconsistencias encontradas y corregidas

- El documento mencionaba modulos no implementados como cambios de carrera y actividades programadas.
- Se indicaba que los estudiantes completarian formularios directamente, pero el sistema esta orientado a usuarios administrativos autorizados.
- Los roles se describian solo como coordinador y decano, mientras que la aplicacion maneja roles como ADMIN, DECANO, SECRETARIO, OPERADOR y CONSULTA.
- La lista de requerimientos funcionales no coincidia con las pantallas reales del sistema.
- Algunas reglas de negocio hablaban de inscripcion de materias y registro de notas, funciones que no forman parte del alcance actual.
- La introduccion repetia la descripcion del capitulo III.
- La descripcion de informes fue actualizada para reflejar filtros por anio, ciclo, materia, tipo de reporte y coordinador, graficos e historico.
- Se ajustaron conclusiones, capacitacion, procesos organizacionales y validacion para coincidir con los modulos realmente implementados.

## Resultado

Se genero una version corregida del documento en formato Word dentro de la carpeta `docs`, manteniendo el archivo original copiado sin modificar.
